# Hospital Data Clerk Portfolio Website

This project is a responsive Next.js portfolio website for Joseph Bigoah Puok Ruop, showcasing hospital data clerk, health information management, data quality, and reporting skills.

## Features

- Modern healthcare-focused design with navy, white, and teal branding
- Responsive portfolio with recruiter-oriented sections
- Interactive hospital dashboard with synthetic records
- Patient registration workflow demo with validation
- Data quality and validation lab with error review
- Spreadsheet and HMIS reporting demonstrations
- Contact and CV application resources
- SEO metadata for relevant job-search terms

## Tech Stack

- Next.js 16 with TypeScript
- Tailwind CSS
- Recharts
- Lucide React
- React Hook Form and Zod

## Getting Started

1. Install dependencies:

   npm install

2. Run the development server:

   npm run dev

3. Open the site in your browser:

   http://localhost:3000

## Production Build

npm run build

## Run Production Server

npm run start

## Deployment

This project is ready for deployment on Vercel or Netlify.

### Vercel

- Import the repository into Vercel
- Use the default Next.js build settings
- Deploy the app

### Netlify

- Import the repository into Netlify
- Set the build command to `npm run build`
- Set the publish directory to `.next`
- Deploy the project

## Notes

- All dashboard and form data is synthetic and intentionally fictional.
- No real patient or confidential hospital data is stored or displayed.
- The contact form is a front-end demo unless a real email backend is configured.
